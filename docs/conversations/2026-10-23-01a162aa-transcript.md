**加为协作者后，他可以直接推送分支，不需要 Fork。推荐“各自分支开发 → 提交 PR → 审核合并”。**

1. **首次把仓库下载到电脑**
   ```bash
   git clone https://github.com/hestia1024/APIELE-TEST.git
   cd APIELE-TEST
   ```

2. **每次开始新任务，更新主分支并创建功能分支**
   ```bash
   git switch main
   git pull origin main
   git switch -c feat/login
   ```
   `feat/login` 换成本次任务的分支名，例如 `feat/order-page`。

3. **写完代码、检查运行正常后，提交并上传**
   ```bash
   git add .
   git commit -m "添加登录功能"
   git push -u origin feat/login
   ```
   提交前检查改动，避免上传密码、密钥和 `.env` 文件。

4. **在 GitHub 发起合并请求**

   打开仓库，点击 **Compare & pull request**，确认目标是 `main`、来源是自己的功能分支，填写说明后点击 **Create pull request**。

5. **你检查代码后合并**

   你在 **Pull requests** 中打开请求，检查通过后点击 **Merge pull request**。合并后，双方下次开发前都先更新 `main`。

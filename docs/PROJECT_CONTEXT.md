# 项目接手信息

## 已确认目标

APIELE-TEST 是个人自用、与同事共同开发、部署到服务器的数据整合网站。详细业务需求还未提供；未来可能大量调用 AI，从非固定结构文本提取信息。当前仅先跑通开发、共享数据库和部署流程，不提前实现 AI 业务。

用户偏好：以结果为主，投入适度；不主动扩大改造或追求无关细节。需要让同事能提供异常描述及编号，由 Codex 查日志定位。通知渠道和自动提醒暂未落地，不能声称已有告警。

## 当前实现

- FastAPI、PyMySQL、python-dotenv，Python 3.12+；单个 HTML/JavaScript 页面由后端直接提供，无前端构建链。
- 页面检查数据库、添加测试记录、展示最近 50 条；表为 `apiele_test_dev.apiele_test_notes`。
- 后端复用空闲连接、一次初始化测试表、合并初始化请求；写入失败不自动重试。
- 页面显示异常编号，服务写轮转日志，日志不记录密码和测试记录正文。
- 云服务器 Docker 运行 MySQL 和网站；网站直接连接同机数据库。服务器网页测试入口目前按用户要求无访问密码。

## 数据库和端口

| 环境 | 连接方式 |
|---|---|
| 本地网站 | `127.0.0.1:8010` |
| 本地 SSH 数据库隧道 | `127.0.0.1:13307` -> 服务器 `127.0.0.1:3307` |
| 服务器网站 | 公网 IP 的 8010 端口 |
| 服务器 MySQL | Docker 容器 `apiele-mysql`，仅映射服务器 loopback 3307，数据库 `apiele_test_dev` |
| 测试表 | `apiele_test_notes`，共享开发库，不包含删除接口 |

Navicat 可使用 SSH 通道管理同一个服务器数据库。数据库密码与 SSH 登录密码不同，存放各自本地 `.env`，仓库仅包含空模板。
